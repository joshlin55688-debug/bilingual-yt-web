# 雙語 YT

貼上 YouTube 影片網址，用**你自己的 Gemini API 金鑰**產生雙語字幕和逐字稿。網頁版，平板、手機、電腦的任何瀏覽器都能開，不用安裝擴充功能。

## 怎麼用

1. 打開網頁，按右上角「設定」，貼上 Gemini API 金鑰（[到 Google AI Studio 申請](https://aistudio.google.com/apikey)），按「測試連線」。
2. 在 YouTube App 按「分享」→「複製連結」，貼到網頁上面的欄位；選影片講的語言，按「載入」。
3. 確認預估費用，按「開始產生字幕」。大約 5–10 秒後開始出現字幕。

- **逐字稿**：點一句跳到那裡，點英文單字查字典（影片會暫停）。
- **上一句／重播／下一句、句尾暫停**：練聽力用。
- **字幕樣式**：原文＋譯文、只顯示譯文、譯文模糊（點字幕看譯文）。
- **全螢幕**：請用網頁上的「全螢幕」按鈕，字幕才會跟著。
- **下載 SRT**：雙語字幕檔，只含已經轉好的部分。
- **設定**：翻譯成什麼語言、翻譯模型、術語表、額外指示、用量與費用。

## 費用

- 字幕是 Gemini 讀影片轉錄的（網頁拿不到 YouTube 自己的字幕），固定用 `gemini-3.5-flash-lite`，約 US$0.13／小時，另加翻譯費。載入時會顯示整部的預估。
- 只轉錄你看到的地方：目前位置那 2 分鐘＋下一段，跳到哪裡轉到哪裡。
- 轉過、翻過的存在這個瀏覽器裡（60 天），重看不再花錢。
- 實際金額以 Google 帳單為準。建議另外申請一把金鑰給這個網頁用，在 Google 那邊設用量上限。

## 限制

- 只能用公開影片：私人、不公開的影片 Gemini 讀不到。
- 上傳者不允許嵌入的影片不能在這裡播放，但還是可以產生逐字稿（點一句會到 YouTube 開啟那個位置）。
- 轉錄只實測過英文演講；其他語言、有背景音樂的影片準確度不確定。

## 隱私

- 沒有我們自己的伺服器。網頁直接連 Google Gemini API（`generativelanguage.googleapis.com`）和 YouTube 的播放器。
- 送給 Gemini 的是：YouTube 影片網址和要轉錄的時間範圍、要翻譯的字幕文字、影片標題、你點的單字。
- 金鑰、設定、用量、快取都只存在你這個瀏覽器（localStorage、IndexedDB），不會上傳。
- 沒有分析、沒有追蹤。

## 開發

- 翻譯與轉錄的核心 `lib/core.js` 和 Chrome 擴充功能共用，用 `node tools/sync-core.mjs <bilingual-translate 資料夾>` 更新。
- 測試：`npm install` 後 `node test/e2e.mjs`（假的 YouTube 播放器＋假的 Gemini，不花錢；平板直放、橫放）。
